# Redesign

Redesigning an existing site. Misreading the mode is the biggest source of bad redesigns, so decide it first.

## 1. Mode

- **Preserve**: modernise without breaking the brand. Dials start from the existing site; motion +1.
- **Overhaul**: new visual language over the existing content and information architecture. Variance and motion +2, density matches.
- **Greenfield**: the brand itself is changing. Treat as a new build.

If it's unclear, ask once: "Should this redesign preserve the existing brand, or start visually from scratch?"

## 2. Audit

Write down the current state before proposing anything. The audit is done when every item has an entry:

- Brand tokens: colors, type stack, logo treatment, radii.
- Information architecture: page tree, primary nav, key conversion paths.
- Content blocks: what works, what is filler.
- Patterns to keep: signature interactions, recognisable hero, copy voice.
- Patterns to retire: AI tells, broken layouts, dead links, generic stock, performance traps.
- Dial reading of the existing site.
- SEO baseline: ranking pages, meta titles, structured data, OG cards. SEO migration is the top redesign risk.

## 3. Choose the scope

- IA, content and SEO sound: **targeted evolution** (levers 1-4 below). Most of the value at much less risk.
- Structural visual debt (broken IA, no system, broken mobile): **full redesign**, content preserved.
- Brand changing: **greenfield**.

## 4. Levers, in order

Stop when the brief is satisfied.

1. Typography refresh: biggest lift per unit of risk.
2. Spacing and rhythm.
3. Color recalibration: unify neutrals, keep the brand accent (a purple brand stays purple).
4. Motion layer sized to the dial.
5. Recompose the hero and key sections.
6. Replace whole blocks, only when unsalvageable.

## 5. Preserve

Keep stable unless the user approves a change: URL slugs and anchor IDs, primary nav labels, form field names and order, section IDs and button names that analytics depend on, logo and wordmark, legal and consent copy, copy voice, and existing accessibility wins (focus states, alt text, keyboard nav, contrast).

## Checklist

- [ ] Mode stated.
- [ ] Audit written, every item filled.
- [ ] Every change traces to a lever, applied in order.
- [ ] Every preserved item untouched, or its change approved by the user.
